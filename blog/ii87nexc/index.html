我给自己造了个私人AI助手-从0到1搭建全记录

约 3448 字大约 11 分钟

AI助手

2026-09-01

通用AI助手不够用？我用开源工具给自己搭了一个私人AI助手，能管理日程、写邮件、查资料、提醒事项，完全掌控自己的数据。本文分享完整的搭建过程和真实使用体验。

我用过几乎所有的AI助手——Siri、小爱同学、小度、ChatGPT、豆包……但总觉得差点意思。

Siri和小爱同学太"笨"了，只能回答简单问题，稍微复杂一点的任务就搞不定；ChatGPT和豆包虽然聪明，但它们是"通用助手"，不知道我的日程、不了解我的工作、记不住我的习惯，每次对话都要从头开始解释。

我想要的是一个真正"懂我"的私人助手：它知道我今天有什么会、记得我上周和客户聊了什么、能帮我写邮件、能提醒我喝水、能在我忙的时候帮我筛选消息。

市面上没有这样的产品，于是我决定自己造一个。

花了两周时间，用开源工具搭了一个私人AI助手，现在已经用了一个月，体验比我预想的好太多。今天把完整的搭建过程分享出来。

整体架构

我的私人AI助手基于以下开源工具搭建：

  • 大模型：通义千问Qwen2.5-72B（部署在本地服务器上，数据不出内网）
  • Agent框架：LangChain（负责任务规划和工具调用）
  • 记忆系统：Chroma向量数据库（存储个人信息和历史对话）
  • 工具层：自定义工具（日历、邮件、待办、提醒等）
  • 前端：一个简单的Web界面（用Gradio快速搭建）

整体架构是这样的：

用户输入 → Agent（理解意图+规划任务） → 调用工具（日历/邮件/待办/搜索） → 整合结果 → 回复用户
                ↓
          记忆系统（存储/检索个人信息）

核心是Agent——它理解用户的意图，决定调用什么工具，然后整合工具的结果给出回复。记忆系统让Agent能"记住"用户的信息和历史对话。

第一步：搭建基础Agent框架

先搭一个最基础的Agent，能对话、能调用工具。

from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_openai import ChatOpenAI
from langchain.memory import ConversationBufferMemory

# 初始化大模型（这里用通义千问的OpenAI兼容接口）
llm = ChatOpenAI(
    model="qwen2.5-72b-instruct",
    api_key="your-api-key",
    base_url="http://your-server:8000/v1",
    temperature=0.1
)

# 定义系统提示词——这是私人助手的"人设"
system_prompt = """你是用户的私人AI助手，名字叫"小助"。

你的职责：
1. 帮助用户管理日程、邮件、待办事项
2. 回答用户的问题，必要时调用工具获取信息
3. 主动提醒用户重要的事情（会议、截止日期、喝水休息等）
4. 记住用户的偏好和习惯，提供个性化的帮助

你的性格：
- 简洁高效，不说废话
- 友好但不过分热情
- 有幽默感，但不刻意
- 尊重用户的隐私，不主动询问敏感信息

重要规则：
- 不确定的事情不要编造，直接说"我不确定"
- 涉及发送邮件、修改日程等操作，必须先确认再执行
- 用户的个人信息严格保密
"""

prompt = ChatPromptTemplate.from_messages([
    ("system", system_prompt),
    MessagesPlaceholder("chat_history", optional=True),
    ("human", "{input}"),
    MessagesPlaceholder("agent_scratchpad"),
])

# 初始化记忆
memory = ConversationBufferMemory(memory_key="chat_history", return_messages=True)

# 创建Agent（先不挂工具，后面再加）
agent = create_openai_tools_agent(llm, [], prompt)
agent_executor = AgentExecutor(agent=agent, tools=[], memory=memory, verbose=True)

这是最基础的版本，能对话但还不能调用工具。下面我们一步步加工具。

第二步：加日历工具

私人助手最核心的功能之一是管理日程。我用的是CalDAV协议，可以对接Google Calendar、Apple Calendar、飞书日历等。

from langchain.tools import tool
import caldav
from datetime import datetime, timedelta

# 日历客户端初始化
client = caldav.DAVClient(
    url="https://your-caldav-server",
    username="your-username",
    password="your-password"
)
principal = client.principal()
calendar = principal.calendars()[0]

@tool
def get_today_schedule() -> str:
    """获取今天的日程安排"""
    today = datetime.now().date()
    start = datetime.combine(today, datetime.min.time())
    end = start + timedelta(days=1)
    
    events = calendar.date_search(start=start, end=end)
    if not events:
        return "今天没有日程安排"
    
    result = "今天的日程：\n"
    for event in events:
        ev = event.icalendar_component
        summary = ev.get("summary", "无标题")
        dtstart = ev.get("dtstart").dt
        result += f"- {dtstart.strftime('%H:%M')} {summary}\n"
    return result

@tool
def create_event(summary: str, start_time: str, duration: int = 60) -> str:
    """创建日程
    
    Args:
        summary: 日程标题
        start_time: 开始时间，格式"YYYY-MM-DD HH:MM"
        duration: 持续时间（分钟）
    """
    start = datetime.strptime(start_time, "%Y-%m-%d %H:%M")
    end = start + timedelta(minutes=duration)
    
    calendar.save_event(
        summary=summary,
        dtstart=start,
        dtend=end
    )
    return f"已创建日程：{summary}，{start_time}，时长{duration}分钟"

加了这两个工具之后，你就可以跟助手说"我今天有什么会"、"明天下午3点帮我安排一个产品评审会"，它会自动调用日历工具。

第三步：加邮件工具

邮件是另一个高频功能。我用IMAP和SMTP协议收发邮件。

import imaplib
import smtplib
from email.mime.text import MIMEText
from email.header import decode_header

@tool
def get_recent_emails(count: int = 5) -> str:
    """获取最近的邮件
    
    Args:
        count: 获取邮件数量，最多20封
    """
    count = min(count, 20)
    
    mail = imaplib.IMAP4_SSL("imap.your-email.com")
    mail.login("your-email", "your-password")
    mail.select("inbox")
    
    _, data = mail.search(None, "ALL")
    email_ids = data[0].split()[-count:]
    
    result = f"最近{len(email_ids)}封邮件：\n"
    for eid in reversed(email_ids):
        _, msg_data = mail.fetch(eid, "(RFC822)")
        msg = email.message_from_bytes(msg_data[0][1])
        subject = decode_header(msg["Subject"])[0][0]
        if isinstance(subject, bytes):
            subject = subject.decode()
        from_ = msg.get("From")
        date = msg.get("Date")
        result += f"- [{date}] {from_}: {subject}\n"
    
    mail.logout()
    return result

@tool
def send_email(to: str, subject: str, body: str) -> str:
    """发送邮件
    
    Args:
        to: 收件人邮箱
        subject: 邮件主题
        body: 邮件正文
    """
    msg = MIMEText(body, "plain", "utf-8")
    msg["From"] = "your-email"
    msg["To"] = to
    msg["Subject"] = subject
    
    server = smtplib.SMTP_SSL("smtp.your-email.com", 465)
    server.login("your-email", "your-password")
    server.sendmail("your-email", [to], msg.as_string())
    server.quit()
    
    return f"已发送邮件给{to}，主题：{subject}"

有了邮件工具，你就可以说"帮我看看今天有什么重要邮件"、"给张三发封邮件，问他项目进度"，助手会帮你处理。

第四步：加提醒和待办工具

提醒功能是私人助手的"灵魂"——它能主动提醒你做事，而不只是被动回答问题。

import schedule
import threading
from datetime import datetime

# 待办事项存储（简单起见用JSON文件，生产环境用数据库）
import json
import os

TODO_FILE = "todos.json"

def load_todos():
    if os.path.exists(TODO_FILE):
        with open(TODO_FILE, "r") as f:
            return json.load(f)
    return []

def save_todos(todos):
    with open(TODO_FILE, "w") as f:
        json.dump(todos, f, ensure_ascii=False, indent=2)

@tool
def add_todo(content: str, deadline: str = None) -> str:
    """添加待办事项
    
    Args:
        content: 待办内容
        deadline: 截止时间，格式"YYYY-MM-DD HH:MM"，可选
    """
    todos = load_todos()
    todo = {
        "id": len(todos) + 1,
        "content": content,
        "deadline": deadline,
        "completed": False,
        "created_at": datetime.now().isoformat()
    }
    todos.append(todo)
    save_todos(todos)
    return f"已添加待办：{content}" + (f"，截止时间：{deadline}" if deadline else "")

@tool
def list_todos(only_pending: bool = True) -> str:
    """查看待办事项
    
    Args:
        only_pending: 是否只显示未完成的
    """
    todos = load_todos()
    if only_pending:
        todos = [t for t in todos if not t["completed"]]
    
    if not todos:
        return "没有待办事项"
    
    result = "待办事项：\n"
    for todo in todos:
        status = "✅" if todo["completed"] else "⬜"
        deadline = f"（截止：{todo['deadline']}）" if todo["deadline"] else ""
        result += f"{status} [{todo['id']}] {todo['content']}{deadline}\n"
    return result

# 提醒功能：定时检查待办，快到截止时间时提醒
def check_reminders():
    """后台线程，定期检查是否有需要提醒的事项"""
    while True:
        todos = load_todos()
        now = datetime.now()
        for todo in todos:
            if not todo["completed"] and todo.get("deadline"):
                deadline = datetime.fromisoformat(todo["deadline"])
                # 提前30分钟提醒
                if 0 < (deadline - now).total_seconds() < 1800:
                    print(f"🔔 提醒：{todo['content']} 将在30分钟后截止！")
        time.sleep(60)  # 每分钟检查一次

# 启动提醒线程
reminder_thread = threading.Thread(target=check_reminders, daemon=True)
reminder_thread.start()

我还加了一个"喝水提醒"——每小时提醒一次喝水休息。这个很简单，用schedule库就行：

import schedule
import time

def drink_water_reminder():
    print("💧 该喝水啦！工作一小时了，站起来活动一下吧～")

schedule.every().hour.do(drink_water_reminder)

# 在后台线程运行schedule
def run_schedule():
    while True:
        schedule.run_pending()
        time.sleep(1)

schedule_thread = threading.Thread(target=run_schedule, daemon=True)
schedule_thread.start()

第五步：加记忆系统

前面提到，通用AI助手最大的问题是"记不住"。我给私人助手加了一个记忆系统，能存储和检索个人信息。

import chromadb
from sentence_transformers import SentenceTransformer

# 初始化记忆数据库
chroma_client = chromadb.PersistentClient(path="./personal_memory")
memory_collection = chroma_client.get_or_create_collection("personal_info")
embed_model = SentenceTransformer('BAAI/bge-small-zh-v1.5')

def store_memory(content: str, memory_type: str = "general"):
    """存储一条记忆"""
    embedding = embed_model.encode([content])[0]
    memory_collection.add(
        ids=[f"mem_{int(time.time())}"],
        embeddings=[embedding.tolist()],
        documents=[content],
        metadatas=[{"type": memory_type, "timestamp": datetime.now().isoformat()}]
    )

def retrieve_memories(query: str, top_k: int = 5) -> str:
    """检索相关记忆"""
    query_embedding = embed_model.encode([query])[0]
    results = memory_collection.query(
        query_embeddings=[query_embedding.tolist()],
        n_results=top_k
    )
    if not results["documents"][0]:
        return ""
    return "\n".join([f"- {doc}" for doc in results["documents"][0]])

然后在Agent的系统提示词里加上记忆的使用说明，并且在每次对话前，先检索相关记忆注入到上下文中。这样助手就能"记住"你的偏好、习惯、历史对话了。

我还加了一个"自动记忆提取"功能——每次对话结束后，让AI判断是否有值得记忆的信息，如果有就自动存起来。比如你说"我对花生过敏"，助手会自动把这条信息存到记忆里，下次你问"这个菜我能吃吗"，它会记得你对花生过敏。

第六步：搭建前端

后端功能都有了，最后搭一个简单的前端界面。我用Gradio，几行代码就能搭出一个聊天界面。

import gradio as gr

def chat(message, history):
    """处理用户输入，返回助手回复"""
    # 检索相关记忆
    memories = retrieve_memories(message)
    # 构建带记忆的输入
    input_with_memory = f"参考用户信息：\n{memories}\n\n用户问题：{message}"
    # 调用Agent
    result = agent_executor.invoke({"input": input_with_memory})
    return result["output"]

# 搭建Gradio界面
with gr.Blocks(title="我的私人AI助手") as demo:
    gr.Markdown("# 🤖 我的私人AI助手")
    chatbot = gr.ChatInterface(
        fn=chat,
        title="小助",
        description="你的私人AI助手，能管理日程、邮件、待办，还能提醒你喝水",
        examples=[
            "我今天有什么会？",
            "帮我看看最近的邮件",
            "添加待办：明天之前完成项目报告",
            "给李四发邮件，约下周一下午开会"
        ]
    )

demo.launch(server_name="0.0.0.0", server_port=7860)

运行之后，访问http://localhost:7860就能看到聊天界面了。手机上也能用——把服务部署到内网服务器，手机浏览器访问就行。

一个月的使用体验

用了一个月，说说真实感受。

最有用的功能：

  1. 日程管理：每天早上问一句"今天有什么安排"，一天的日程就清楚了。快到会议时间会提醒我，再也没错过会。
  2. 邮件处理：不用自己翻邮箱了，问一句"有什么重要邮件"，助手会帮我筛选。写邮件也方便，说个大意它就帮我写好。
  3. 待办提醒：快到截止时间会提醒我，拖延症改善了很多。
  4. 记忆功能：它记得我的偏好（比如"我喜欢简洁的回复"）、我的习惯（比如"我每周三下午健身"），回复越来越个性化。

不太完美的地方：

  1. 工具调用偶尔出错：比如创建日程的时候时间格式不对，需要重试。这个可以通过优化提示词和加参数校验来改善。
  2. 记忆检索不够精准：有时候会检索到不相关的记忆，干扰回答。需要优化检索策略。
  3. 前端比较简陋：Gradio的界面比较简单，不如商业产品好看。但够用了，以后可以换更专业的前端。
  4. 部署和维护成本：自己搭需要一台服务器，需要维护模型、数据库、各种工具。对于非技术用户来说门槛比较高。

总体评价： 虽然有各种不完美，但这是我用过的最"懂我"的AI助手。因为它完全为我定制，知道我的日程、我的邮件、我的待办、我的习惯，而且数据完全在我自己的服务器上，不用担心隐私问题。

这种"完全掌控"的感觉，是任何商业AI助手都给不了的。

我的一些思考

自己搭私人AI助手这件事，让我对AI的未来有了一些思考。

现在的AI助手都是"通用型"的——一个模型服务亿万用户，每个人得到的都是差不多的体验。但每个人的需求、习惯、工作方式都不一样，通用助手不可能满足所有人。

未来的AI助手应该是"私人定制"的——每个人都有自己的AI助手，它了解你的一切，能帮你处理各种事务，而且数据完全由你掌控。就像每个人都有自己的手机、自己的电脑一样，未来每个人都会有自己的AI助手。

现在这个趋势已经开始了——各种开源大模型、Agent框架、工具链越来越成熟，个人搭建私人AI助手的门槛越来越低。我这个两周搭出来的版本还很粗糙，但已经能解决很多实际问题了。随着工具链的成熟，未来搭建私人AI助手会像搭博客一样简单。

当然，私人AI助手也有风险。数据安全、系统稳定性、错误操作的后果……这些都是需要考虑的问题。我的建议是：从小功能开始，先做"只读"的功能（查日程、查邮件），确认稳定了再加"写操作"（发邮件、创建日程），而且写操作一定要加确认步骤。

如果你也想有一个真正"懂你"的AI助手，建议你试试自己搭一个。不用一开始就很复杂，就从"能对话+能查日程"开始，然后慢慢加功能。当你用了一段时间，发现它越来越懂你的时候，你会觉得这一切都值得。

AI的未来不是"一个万能的AI"，而是"每个人都有自己的AI"。这个未来，已经来了。
